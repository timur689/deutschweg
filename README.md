# Deutschweg

Немецкий с нуля до B1: уроки, правила, методичка «как что определять», словарь, интервальное повторение, тренажёры и пробный экзамен.

**Открыть:** https://timur689.github.io/deutschweg/

## Установка как приложение

- **iPhone / iPad (Safari):** «Поделиться» → «На экран „Домой"».
- **Android (Chrome):** ⋮ → «Установить приложение».
- **Mac / Windows (Chrome, Edge):** значок установки в адресной строке.

После первого открытия приложение работает и без интернета. Прогресс хранится на устройстве; перенести его на другое устройство можно в «Практика → Статистика → Перенос прогресса».

## Сборка

Эта папка собирается скриптом `build-web.py` из исходников приложения; вручную файлы здесь не правятся.
